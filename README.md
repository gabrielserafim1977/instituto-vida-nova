# Instituto Vida Nova

Projeto desenvolvido para a disciplina de Desenvolvimento Front-end.

O site representa uma ONG fictícia chamada Instituto Vida Nova, com páginas voltadas para apresentação institucional, projetos sociais, cadastro de voluntários e contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- localStorage
